PIPE-SEQ

2026

Plugin
Performance

Performance using a custom-built sequencer system plugin for VCV Rack. The plugin, inspired by factory building games, utilizes a modular pipe system for building different constructions in which each pipe can be utilized as a trigger.

The plugin was born out of a larger exploration of VCV Rack as a creative platform beyond emulating the physical Eurorack. Using custom plugins to experiment with visual aspects, animated modules, randomly generated modules, nonsensical modules, patterns, and more.
